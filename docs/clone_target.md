## 复刻目标（术语约定）

- **复刻目标 = Apple App Store 上的「随手记专业版」**。
- 后续所有聊天中，凡涉及「复刻」「复刻目标」「参考的 App」「对标的产品」「原版」等表述，一律指 **Apple App Store 上的随手记专业版**，无需再次确认。
- 发行方：深圳市铭数信息有限公司（金蝶旗下）。
- 复刻聚焦其核心主链路：记账 + 报表 + 账户 + 预算 + 多账本（云同步等服务端能力按需另议）。

## 目录映射约定（强制）

- 仓库根目录下的 `index.md` 定义了 `Src/` 与 `Tests/` 各目录 path 及其应放置的源码/文件类型的映射关系。
- **凡是为本项目生成或提交的代码、文件，必须严格遵循 `index.md` 中的目录映射关系放置**，不得随意乱放。
- 新增目录或调整结构时，必须同步更新 `index.md` 的映射条目，保持文档与实际结构一致。
- 每个被测源码文件的测试须放在 `Tests/` 中与 `Src/` 相同的相对路径下（如 `Src/Domain/UseCases/Finance.swift` → `Tests/Domain/UseCases/FinanceTests.swift`）。
