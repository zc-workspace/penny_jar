# penny_jar 🐷

> 一款参考 App Store「随手记」设计的 iPhone 记账软件。

`penny_jar` 参照随手记的核心记账体验设计，聚焦「记账 + 报表 + 账户 + 预算 + 多账本」这条主链路，目标是打造一款纯原生、数据本地存储、不出设备的个人记账工具。

## 设计目标

- **记一笔**：支出 / 收入 / 转账，分类九宫格 + 自定义数字键盘，支持照片凭证、成员、项目标签
- **流水**：按日分组、类型筛选、搜索、编辑、删除
- **账户**：现金 / 储蓄卡 / 信用卡 / 电子钱包 / 投资，资产 / 负债分组、实时余额、净资产
- **情景账本**：生活 / 生意 / 旅游 / 结婚 / 宝宝 / 装修 / 汽车 / 多人账等模板，多账本、设默认
- **预算**：总预算 + 分类预算，进度条、超支提醒
- **报表**：分类占比饼图 + 分类明细 + 收支趋势
- **数据导出**：导出 CSV，可存文件或发邮件

## 技术选型

| 维度 | 选择 | 理由 |
|---|---|---|
| 语言 | Swift 5 | 苹果官方语言，iOS 首选 |
| UI | SwiftUI | 声明式，一套代码适配 iPhone / iPad |
| 存储 | SwiftData（iOS 17+） | `@Model` 声明即建表，可平滑升级 CloudKit 同步 |
| 图表 | 纯 SwiftUI 手绘 | 零第三方依赖，便于定制 |
| 最低系统 | iOS 17.0 | SwiftData 要求 |
| 工程生成 | XcodeGen（`project.yml`） | 工程结构文本化，纯净、可版本化 |

## 后续规划

- **iCloud 同步**：SwiftData 加 `cloudKitDatabase: .automatic` 即可多设备同步
- **多币种**：补汇率换算与账本币种选择
- **周期账**：定时生成固定支出（房租、订阅）
- **安全**：Face ID / 密码锁（LocalAuthentication）
- **Widget & Apple Watch**：快速记账、资产概览小组件
